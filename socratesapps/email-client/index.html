Before you install

Add mail_client_secret_key to odoo.conf before installing: mail passwords are encrypted with it and it never lives in the database, so back it up. You need an IMAP server and an outgoing mail server configured in Odoo. We tested with a real IMAP/SMTP mailbox (Zoho Mail) and an automated suite of more than 260 tests; Gmail and Microsoft 365 sign-in and Dovecot/mailcow setups are covered by unit tests only. Based on the open-source Mail Client by Albirru Solutions (LGPL-3); our changes are listed in CHANGES.md.
