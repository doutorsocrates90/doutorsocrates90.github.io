# this is my art

Portfolio of Ricardo Ruiz Freire, published at [thisismy.art.br](https://thisismy.art.br) with GitHub Pages and Jekyll.

- `index.md`, `consulting.md`, `projects.md`, `teachings.md`, `texts.md`, `lectures.md`, `curation.md`, `designs.md`, `awards.md`: main sections
- `post/`: individual project, consulting and teaching pages (front matter: `title`, `kicker`, `lede`, `coverImage`)
- `_layouts/default.html`, `_includes/`, `assets/css/site.css`: layout, card components and styles
- `images/`: images and generated covers

Content is Markdown; the layout supplies navigation, fonts (Fraunces and Inter) and dark mode.
